# Завантаження головної та каталогу — 22.10.2026

Перевірено публічний сайт і локальну dev-версію. Chrome, нові контексти, ширини 390/1440 px. Публічні заміри: CPU ×4, звичайна мережа. Це по одному лабораторному проходу, а не польовий 75-й перцентиль або звіт PageSpeed.

| Публічна сторінка | Ширина | TTFB | LCP | CLS |
|---|---:|---:|---:|---:|
| / | 390 | 0.72 с | 2.29 с | 0.00000 |
| / | 1440 | 0.54 с | 1.23 с | 0.00000 |
| /katalog | 390 | 1.05 с | 1.58 с | 0.00086 |
| /katalog | 1440 | 0.42 с | 0.83 с | 0.00135 |

У цих проходах: HTTP 200, без помилок JavaScript, невдалих мережевих запитів, відповідей HTTP 4xx/5xx і горизонтального переповнення. Перевірені зображення першого екрана завантажені. Це не гарантія для всіх пристроїв і сценаріїв.

## Виявлені проблеми

- Відкриття входу й Escape на публічній головній: INP 264 мс при ширині 390 і 192 мс при 1440, CPU ×4. Мобільний результат вище цілі 200 мс. Контекст має мобільну ширину, взаємодія — натискання Playwright, не фізичний телефон.
- У каталозі невеликі зсуви біля ціни: CLS приблизно 0,00086–0,00135. Це нижче межі 0,1, проте анімація геометрії генерувала повторні layout-shift записи.
- Перший локальний HTTP-запит до каталогу перевищив 8 с; повторний завершився приблизно за 0,84 с. Dev-сервер компілює маршрути на запит; його час не можна переносити на production.

## Локальні виправлення

- У ціні ProductCard замінено transition-all на переходи кольору, фону й тіні. Після правки мобільний локальний прохід має один layout-shift замість 20, залишковий CLS 0,00086.
- Підготовка форми входу для гостя запускається після window.load у вільний час браузера. Save-Data та 2G виключені, запланована робота скасовується при зміні авторизації/демонтуванні.
- Відкриття та підключення компонента авторизації переведено в React transition.
- Оновлено застарілий mock catalog-live під поточний пакетний API й TTL 45 с. Продуктовий API не змінювався.

Останній локальний замір входу після правок: INP **272 мс**, CPU ×4, CLS 0. Ціль 200 мс ще не досягнута; стабільне прискорення не підтверджене. Dev-версію не слід прямо порівнювати з production. Після публікації потрібен повторний production-замір, а для висновків про реальних користувачів — польові дані. Зміни не опубліковані.

## Функціональні перевірки

- Пошук OC90 у локальному каталозі: 4 картки, без помилок JavaScript.
- Наступна сторінка: адреса /katalog?page=2, інші 16 товарів, без помилок JavaScript.
- Авторизація з довгим ім’ям і затримкою профілю: незмінні висота панелі, положення привітання, карток вигод і наступного блоку на 320, 390, 768, 1024, 1440 px. Авторизація змодельована; реальний обліковий запис не використовувався.
- Пройшли test-direct-catalog-server, test-catalog-request-lifecycle, test-catalog-live, test-catalog-image-optimize, test-home-auth-layout, TypeScript та ESLint змінених компонентів.

Орієнтири: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1. [Документація Google Web Vitals](https://web.dev/articles/vitals).

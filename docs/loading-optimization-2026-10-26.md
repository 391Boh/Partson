# Оптимізація завантаження — 26.10.2026

Локальні зміни, без публікації. Перевірено production-компіляцію Next.js на порту 3102: Chrome, CPU ×4, мережа без обмеження, нові контексти 390/1440 × 900 px. По одному проходу; серверні та графічні кеші могли бути прогріті. Це лабораторні дані, не польові показники або оцінка PageSpeed.

## Зміни

- Каталог, авто, групи й виробники отримали спільний критичний CSS з усіма серверними стилями й фільтром, який підключається після гідратації. Блокуючий CSS зменшено з 175260 до 57446 байтів gzip (приблизно 67%). Повний CSS завантажується асинхронно; загальний обсяг CSS не зменшився.
- Додаткові статті винесено в Suspense: основний текст, обкладинка й SEO статті більше не чекають на необов’язковий список. Під звичайні три рядки зарезервовано місце.
- Завчасне завантаження каталогу знову працює після спливу session-кешу. Свіжий кеш і спільні одночасні запити збережені.
- Завершено оформлення FAQ: виразний заголовок, нумеровані нативні details/summary, клавіатура, фокус і reduced-motion.

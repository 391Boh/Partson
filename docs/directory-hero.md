# Шапка довідників

Спільний `CatalogHubHero` використовує наявні фото, затемнення та CSS-маску з градієнтною прозорістю. Фото й текст не мають циклічної анімації. Акцент заголовка — суцільний колір; початковий текст H1 зберігається.

Панель «Авто / Категорії / Виробники» має звичайні посилання, активний стан, видимий фокус і мінімальну висоту 46 px на телефоні. Ширина пунктів враховує довжину назв. Наведення змінює прозорість накладки, не зсуваючи посилання. В режимі зменшеної анімації переходи панелі вимикаються.

Глобальний хедер прозорий угорі всіх сторінок `/auto`, `/groups`, `/manufacturers` та їхніх вкладених рівнів. Наявний спостерігач у `PageHeader` повертає фон після прокручування. Фото починається від верхнього краю екрана; відступ контенту всередині шапки враховує `--header-height`. Окремий `.model-hero` вже містить цей відступ і зберігає власні правила.

`DirectoryNavigationWarmup` після завантаження поточної сторінки готує дві сусідні сторінки через спільний кеш `route-prefetch`. Запити рознесені в часі. Фото використовують ті самі `srcset` і `sizes`, що й видима шапка, з низьким пріоритетом. Економія трафіку, 2G, офлайн та прихована вкладка зупиняють цю необов’язкову роботу; демонтування компонента скасовує очікування.

Стани `loading.tsx` для трьох розділів залишають навігацію доступною під час очікування даних. Вони не запускають фонове підвантаження сусідніх сторінок. Їхні стилі включено в критичний CSS каталогу, щоб скелетон одразу мав правильні розміри.

Перевірки: `scripts/test-directory-hero.mjs` (320 / 390 / 768 / 1440 px, три розділи, клавіатура, hover, скорочена анімація, налаштування мережі й скасування), `scripts/test-route-prefetch.mjs`, `scripts/test-style-splitting.mjs`. Новий браузерний сценарій включено у `npm run test:browser`.

# Адаптивність публічних сторінок — 03.11.2026

Спільна рамка головної, каталогу, довідників, товару, шапки та футера плавно розширюється до 1840 px. На 4K та широкоформатних моніторах контент залишається центрованим; довгі вступні тексти зберігають обмежену ширину.

- Каталог: 1 / 2 / 3 / 4 / 5 / 6 колонок від 320 до 3840 px. Розрахунок віртуальних рядків і пріоритет завантаження фото враховують нові колонки.
- Довідники: до 6 колонок, категорії — до 3, по три рядки на сторінці. Пагінація перебудовується при зміні ширини.
- Шапка: компактні дії на планшетах і невеликих ноутбуках; два рядки до 374 px. Висота шапки, відступи сторінок та липкі панелі використовують спільну CSS-змінну.
- Сенсорні екрани: кнопки керування від 44 px; поля введення від 16 px на мобільних пристроях.

## Перевірено

Локальна production-збірка (`build:compile`), TypeScript, ESLint та всі 43 модульні тести пройшли.

`test-responsive-layout.mjs`: 11 реальних сторінок × 14 розмірів = 154 перевірки у Chrome. Ширини 320, 360, 390, 640, 768, 820, 1024, 1280, 1440, 1920, 2560, 3440, 3840 px; окремо горизонтальний екран 844 × 390. Перевірено переповнення, перетин кнопок шапки, кількість колонок, пагінацію та пошуковий діалог у двох орієнтаціях.

`test-catalog-rendering.mjs`: каталог зі 160 тестовими товарами, зміна 1–6 колонок і прокручування до останнього товару без втрати віртуальних рядків.

`test-product-card-responsive.mjs`: справжні картки товарів із довгими назвами, артикулами, звичайною та акційною ціною на 10 ширинах від 320 до 3840 px.

Тести виконано з емуляцією сенсорного екрана. Фізичні пристрої не перевірялися. Для незалежності від доступності 1С заповнені каталоги й картки додатково перевірено на контрольованих тестових даних.

## Повторний запуск

Після підготовки CSS (`npm run test:prepare`):

```sh
node scripts/test-catalog-rendering.mjs
node scripts/test-product-card-responsive.mjs
TEST_ORIGIN=http://localhost:3118 node scripts/test-responsive-layout.mjs
```

`TEST_ORIGIN` має вказувати на локальний preview. Для встановленого Chrome задайте `TEST_BROWSER_CHANNEL=chrome`; знімки можна зберегти через `RESPONSIVE_SCREENSHOTS=/tmp/partson-responsive`.

## Головна: текст і списки на телефоні

Опис у першому екрані збільшено до 16–18 px, вступи підбору авто, категорій і виробників — до 16–17 px. Підсилено насиченість і контраст; збільшено також текст нижнього описового блоку магазину.

До 767 px списки показують одну повну сітку з кнопками пагінації, без внутрішнього горизонтального або вертикального прокручування. Виробники розміщені у двох колонках. Блок авто росте разом із вмістом на кроках вибору моделі й модифікації; роки на телефоні обираються через звичайний select. На широкому екрані зберігається карусель і вибрана сторінка при зміні ширини.

Регресія `test-home-mobile-pickers.mjs` перевіряє три списки на 320, 390, 640 і 767 px, кнопки сторінок, відновлення каруселі на 1440 px та кроки підбору авто. Дані категорій і моделей контрольовані всередині браузерного тесту. Запуск: `TEST_ORIGIN=http://localhost:3118 node scripts/test-home-mobile-pickers.mjs`.

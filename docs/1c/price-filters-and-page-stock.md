# Фільтри ціни, залишки сторінки і фото без `codes`

Зміни внесено в `CommonModules/ОбщегоНазначения/Ext/Module.bsl` репозиторію
конфігурації `~/Projects/partson-1c-config` поверх коміту `65b9795f`. У робочу
базу їх потрібно завантажити разом із `65b9795f`. База файлова, тому для
оновлення потрібен монопольний доступ. Код не перевірено виконанням у 1С;
файл `ПолучитьТоварыПакетом_оптимизированная.bsl` у цій теці старіший і
нових змін не містить.

## `ПолучитьТоварыПакетом` (`allgoods`)

- `ТолькоБезЦены: true` — лише товари з `ЦінаПрод <= 0` або без запису в
  довіднику `Ціна`. Працює з курсором `ПослеКода`, `ПрямаяСтраница` і
  загальною кількістю, як і `ТолькоСЦеной`.
- Відповідь завжди містить `"price_filter": "sale_v1"`: `ТолькоСЦеной`
  означає ціну продажу, `ТолькоБезЦены` підтримується. Сайт вмикає прямі
  сторінки режиму «спочатку з ціною» лише після цієї ознаки.
- Якщо потрібен повний набір (ціновий фільтр, пряма сторінка), але залишки не
  беруть участі у відборі, `ВТОстатки` лишається порожньою, а залишки
  рахуються окремим запитом лише для товарів сторінки (п. 20.1). Раніше
  регістр `ТоварыНаСкладах` агрегувався для всіх ~10 тис. товарів на кожен
  запит.

## `ПолучитьФотоПакетом` (`getimages`)

Гілка без `codes` використовувала `ЗначениеЗаполнено` в тексті запиту і
завершувалася помилкою «Ошибка запроса фото». Умову замінено на порівняння з
`ЗНАЧЕНИЕ(Справочник.НоменклатураПрисоединенныеФайлы.ПустаяСсылка)`. Сайт цю
гілку більше не викликає: відповідь на `codes` вважається остаточною.

## Перевірка після завантаження

```sh
node --env-file=.env.local scripts/probe-onec-price-features.mjs   # лише читання
node scripts/test-catalog-priced-first.mjs
node scripts/test-product-stock.mjs
```

Ознаки успіху: `allgoods` без `ВключатьЦінуЗакуп` не віддає `ЦінаЗакуп`,
`prices` віддає `Акція`, а пряма сторінка каталогу далі ~5000-го товару
відкривається без `directPageUnsupported`.

## HTTP-сервіс `serv` (`HTTPServices/serv/Ext/Module.bsl`)

- Усі методи віддають `Content-Type: application/json; charset=utf-8`.
- `getdata` (GET), `getprod`, `getauto`, `prices`, `getinfo` тепер перехоплюють
  помилки й відповідають JSON 500 з коротким описом (`КраткоеПредставлениеОшибки`)
  замість HTML-сторінки 1С з шляхами модулів.
- `getdata` (GET) викликав `НайтиТовары()` без обов'язкового параметра й
  завжди падав; тепер передає `{}`.

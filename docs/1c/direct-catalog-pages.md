# Прямий перехід на сторінку каталогу

Сайт готовий отримувати лише потрібну сторінку. Для ввімкнення потрібно
замінити функцію `ПолучитьТоварыПакетом` у модулі HTTP-сервісу 1С функцією
з [підготовленого файлу](./ПолучитьТоварыПакетом_оптимизированная.bsl)
і застосувати оновлення конфігурації в робочій базі. Наявні допоміжні функції
цього модуля залишаються потрібними.

Перевірка поточного сервісу показала: `allgoods` та `getdata` повертають
однакові перші товари для сторінок 1 і 2, ігноруючи `НомерСтраницы` та
`Смещение`. Тому зміни лише в JavaScript не можуть увімкнути прямий перехід.
Код 1С в цьому репозиторії підготовлений, але віддалено не встановлений
і не перевірений виконанням у 1С.

## Новий запит

Приклад останньої сторінки для 10 107 товарів, по 16 на сторінці:

```json
{
  "ПрямаяСтраница": true,
  "Смещение": 10096,
  "Лимит": 16,
  "ВключатьФотоBase64": false
}
```

Відповідь містить лише 11 товарів цієї сторінки та підтвердження режиму:

```json
{
  "success": true,
  "pagination_mode": "offset_v1",
  "offset": 10096,
  "total_count": 10107,
  "has_more": false,
  "next_cursor": "",
  "items": []
}
```

`items` вище скорочено для показу структури. Під час реальної перевірки
в ньому мають бути 11 товарів.

Модуль для сторінок у другій половині каталогу читає кінцеву вибірку
у зворотному порядку і повертає товари у звичайному порядку. Ціни,
наявність, сортування й основні фільтри враховуються до вибору сторінки.
`Поиск` разом із `ПолеПоиска` задає єдиний пошук для нумерації його результатів.

Звичайна курсорна пагінація з `ПослеКода` зберігається. Без підтвердження
`offset_v1` сайт використовує попередній, повільніший спосіб; він не
показує першу сторінку під номером останньої. Після оновлення 1С оновіть
сторінку браузера, щоб одразу повторити перевірку можливостей сервісу.
Складені вибірки для кількох автомобілів або розгорнутої ієрархії поки
залишаються курсорними.

## Перевірки сайту

```sh
node scripts/test-direct-catalog-server.mjs
node scripts/test-direct-catalog-page.mjs /path/to/playwright/index.mjs
```

Браузерний тест перевіряє один запит для переходу з першої на 632-гу
сторінку, лише 11 карток у результаті, повернення назад, 48 товарів на
сторінці та відновлення після помилки. Він використовує контрольовані
відповіді сервісу; це не заміна перевірки встановленого модуля 1С.

# Пошук товарів за застосуванням з опису 1С

Вибір авто зберігає марку, модель, рік, об’єм, потужність, КПП та привід у
параметрі `vehicle` каталогу. Ця конфігурація входить у ключі кешів і запити
списку, підрахунку та параметрів товарів. Посилання зберігає конфігурацію;
видалення авто й скидання фільтрів прибирають її.

## Джерело даних

Застосування вже міститься в `Описание` товарів 1С. Реальний приклад:

```text
VW PASSAT B3/B4 1.6-2.8 02.88-05.97

Монтажна позиція    задн
Сторона монтажу     прав / лів
```

`getdata` ігнорує `selectedCars`; передавати лише лейбл авто недостатньо.
`allgoods` використовується для отримання кандидатів за базовою моделлю з
`ВключатьОписание=true`. Перевірка застосування виконується в Next.js перед
пагінацією, сортуванням і підрахунком результатів.

## Правила

- Перевіряються марка (включно з VW/Volkswagen), модель і вказане покоління.
- Рік має входити в зазначений діапазон; підтримуються місяць/рік,
  двозначні роки та відкритий початок діапазону.
- Об’єм двигуна перевіряється за переліком або діапазоном.
- Явні обмеження потужності (кс/HP/PS), КПП і приводу не повинні суперечити вибору.
- Інша марка після `;` утворює окреме застосування: її параметри не можуть
  підтвердити попередню модель. Звичайні табличні характеристики не є застосуванням.
- Якщо обрано покоління/рік, одного загального запису `VW PASSAT` недостатньо:
  потрібне покоління або діапазон років. Товари без опису не підтверджуються.
- Порожній результат та помилка 1С не розширюються до всього каталогу або
  іншого покоління. Прямий offset для конфігурації вимкнений; діє курсор.

Парсер: `app/lib/vehicle-fitment.ts`. Спільний потік пошуку:
`app/lib/catalog-server.ts`, `app/lib/catalog-search.ts`.

## Межі даних

Вільний текст не є повним каталогом технічної сумісності. Відсутні в описі
обмеження двигуна, КПП чи приводу не вигадуються. Коди двигунів, OEM/VIN,
неописані псевдоніми поколінь та довільні формати потребують окремих даних або
розширення правил на перевірених прикладах. Підбір використовує записане в 1С
застосування, а не дає додаткову гарантію сумісності.

Для повної структурованої сумісності 1С може надалі повертати масив застосувань
(марка, модель/кузов, інтервал років, двигун, КПП, привід) і фільтрувати його
безпосередньо в `allgoods`. Це прибере залежність від формату опису.

## Перевірки

```sh
node scripts/test-vehicle-fitment.mjs
node scripts/test-catalog-search.mjs
node scripts/test-search-relevance.mjs
node scripts/test-product-params.mjs
npx tsc --noEmit --pretty false
```

Тести застосування перевіряють покоління, роки, об’єм, потужність, КПП,
привід, кілька марок, пропуск несумісних пакетів, відсутність дублів між
сторінками, нульовий результат і збій джерела.

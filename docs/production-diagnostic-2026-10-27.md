# Діагностика production PartsON — 27.10.2026

Production працює й проходить основні перевірки доступності. Пріоритетні проблеми: застарілий body-parser на auth-сервісі, заповнення диска, періодичні таймаути 1С. Це діагностика, а не повний пентест чи підтвердження відсутності вразливостей.

Перевірено живий https://partson.shop, стан сервера через SSH, установлені версії, вибірку логів і поточний локальний проєкт. Активний production: `3be2bcd`, `/var/www/Partson-release-20261027-3be2bcd`; локальний HEAD на завершення перевірки: `ee8fb48`. Локальна збірка не тотожна активному релізу. Точні вимірювання збережені в сусідньому JSON.

### Що означають security-попередження

Лічильник npm — це оцінка пакетів за версією, а не доказ експлуатації всіх advisory в цьому проєкті.

- **body-parser 2.3.0:** умови конфігурації відповідають описаному ризику падіння процесу при обробці стисненого HTTP-тіла. Небезпечний payload на production не відправлявся. Виправлення та workaround описані в [офіційному advisory](https://github.com/advisories/GHSA-27r3-jxmh-p828).
- **Next.js 16.3.8:** npm позначає пакет critical. Для image-optimization advisory фактично використовуваний `sharp` — **0.35.5**, що відповідає опублікованому workaround; `dangerouslyAllowSVG:true` не знайдено. [Advisory Image Optimization](https://github.com/advisories/GHSA-2464-fhr4-w9xw).
- Для [Next `use cache` RCE](https://github.com/advisories/GHSA-673q-mjm6-r5xr) у перевірених app-файлах не знайдено директив `use cache`. Для [Server Actions DoS](https://github.com/advisories/GHSA-p3m5-59mp-jv5r) не знайдено директив `use server`. Це знижує підтверджену застосовність до поточного коду, але не замінює оновлення; advisory рекомендує оновити Next.js, виправлена версія — 16.4.1.
- **Sentry 10.73.0:** `tunnelRoute` у конфігурації production відсутній. Умови конкретного middleware-bypass advisory не підтверджені. Патч для гілки 10 — 10.75.2. [Advisory Sentry](https://github.com/advisories/GHSA-mchm-gjx6-7h55).
- **follow-redirects 1.16.0:** high, виправлена гілка починається з 1.16.1. **fast-uri 3.1.8:** moderate, виправлення з 3.1.9. Це результати npm audit; доступність уразливих сценаріїв цих транзитивних пакетів не перевірялась.

Є таймаути getdata/allgoods/getimages/getinfo та 2 рядки ECONNREFUSED; TypeError/ReferenceError/ENOENT у цій вибірці не знайдені. Останні перевірені auth-error — порожні.

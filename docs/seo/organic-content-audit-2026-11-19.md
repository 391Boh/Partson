# SEO-аудит текстів, оформлення та індексації PartsON

Дата: 19 листопада 2026 року. Сайт: https://partson.shop.

## Висновок

На перевірених сторінках основні технічні сигнали вже присутні. Найпомітніші проблеми — невідповідність текстів новому асортименту, назва розділу «Інше» без пояснення вмісту та ризик втрати посилань на нові категорії через застарілі лічильники. Ці проблеми виправлено в робочому коді.

Мета змін — точніше відповідати на запит покупця та зберігати доступність нових сторінок для обходу. Зростання позицій або трафіку не вимірювалося: доступ до Search Console й статистики органічних конверсій у цій сесії не використовувався. Зміни ще потрібно опублікувати.

## Обсяг і докази

Перевірено 29 публічних URL: головну, каталог, пошук, параметр `page=2`, довідники, стару та нову категорії, три підгрупи, виробника BOSCH, марку Ford, моделі Focus II і Golf IV, блог і статтю, шість нових товарів та чотири інформаційні сторінки.

| Перевірка HTTP HTML | Результат |
|---|---|
| Відповіді HTTP 200 | 28 із 29 URL |
| Редирект | `/manufacturers/bosch` → `/manufacturers/bosch-2wkr2o`, HTTP 308; ціль окремо перевірена, HTTP 200 |
| H1 | Один на кожній із 28 сторінок HTTP 200 |
| Canonical | Один у кожній із 29 відповідей |
| Дозвіл індексації | 26 сторінок HTTP 200 |
| `noindex` | Внутрішній пошук і параметризований `/katalog?page=2` |
| Синтаксичні помилки JSON-LD | Не виявлені у вибірці |
| Нові товари | Усі шість вибраних сторінок: HTTP 200, self-canonical, дозвіл індексації, Product/Offer |

Це вибірковий обхід, а не перевірка кожного товару та не підтвердження фактичної індексації Google. Сирі результати: `output/seo/organic-content-public-audit.json` — локальний файл, який ігнорується Git.

Попередній [аудит нових надходжень від 18 листопада](new-arrivals-indexing-2026-11-18.md) окремо містить перевірку sitemap, усіх 22 нових груп і відповідності імпортованих SKU. Його числові дані стосуються знімка на ту дату, а не нового повного обходу всіх товарів сьогодні.

## Що змінено

### 1. Назви, сніпети й категорії

- Видима назва `/groups/inshe`: **«Автоаксесуари та інструмент»**. Адреса, slug і значення фільтра 1С **«Інше»** збережені.
- Опис цього розділу пояснює асортимент: аксесуари, автохімія, інструмент, освітлення та приладдя для ремонту.
- Для 22 підгруп додані різні вступи й критерії: аромат/формат/кріплення; робочі розміри/посадка/склад набору; цоколь/напруга/застосування; вантажопідйомність/висота/опора тощо.
- У сніпетах цих груп прибрано недоречний VIN. Критерії описують, **що перевірити**, і не приписують конкретному товару відсутні характеристики.
- У нижньому блоці аксесуарів посилання ведуть до товарів, батьківської категорії та інших категорій; автомобільний підбір збережений для звичайних запчастин.

Google рекомендує описові заголовки та унікальні змістовні описи. Символьні бюджети в коді — редакційний орієнтир, а не гарантований розмір сніпета: відображення залежить від запиту й ширини екрана. Джерела: [заголовки в пошуку](https://developers.google.com/search/docs/appearance/title-link), [метаописи](https://developers.google.com/search/docs/appearance/snippet).

### 2. Картки товарів і FAQ

| Було | Стало |
|---|---|
| AREON FW06: «…для Areon Fresh Wave Ocean… перевірка сумісності за VIN» | Назва товару, аромат, бренд і артикул без трактування аромату як автомобіля |
| Набір головок: FAQ «Чи підійде … до мого авто?» | Перевірка профілю, розмірів, посадкового квадрата й складу набору |
| Вступ і позначка на картці освіжувача пропонували VIN | Доречне уточнення характеристик і комплектації; автомобільний сценарій залишився для запчастин |
| Домкрат: загальна порада про модифікацію авто | Критерії вантажопідйомності, висот підхоплення/підйому й опори |
| FAQ був клієнтським компонентом без необхідності | Серверний компонент із нативними `<details>`; відповіді й розкриття доступні без окремої клієнтської логіки FAQ |

Видимий FAQ і FAQPage JSON-LD продовжують використовувати одне джерело тексту. Це забезпечує узгодженість даних, але не дає окремої обіцянки видимості в Google: Google припинив показ FAQ rich results із 7 травня 2026 року. FAQ зберігається передусім як допомога покупцеві. Джерело: [оновлення Google Search, травень 2026](https://developers.google.com/search/updates#may-2026).

### 3. Виявлення нових категорій

Раніше наявність підрахунку в будь-якому старому розділі дозволяла відфільтрувати як порожній новий розділ, якого ще немає у знімку лічильників. Тепер ознака `countsKnown` передається з підрахунку конкретної категорії до довідника й sitemap.

- Новий кореневий розділ, відсутній у старому знімку, зберігає посилання на себе, підгрупи та кінцеві категорії.
- Підтверджено порожні категорії залишаються виключеними за чинною політикою.
- Справжній нуль і невідомий підрахунок не підміняють один одного в тексті.
- Змінено ключ кешу sitemap груп, щоб після публікації не використовувався попередній результат цієї логіки.

Це захист від частково застарілого знімка, а не заміна регулярного оновлення даних після імпорту. Він не встановлює окрему дату появи кожної нової підгрупи всередині вже підрахованого кореневого розділу.

Google знаходить сторінки за посиланнями та sitemap; натискання кнопок і введення запиту не замінюють ці механізми. У `DirectoryCollection` посилання зберігаються в серверному HTML, хоча частина візуально прихована локальною пагінацією. Це відрізняється від контенту, який завантажується лише після натискання. Джерело: [пагінація та поступове завантаження](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading).

У поточній роботі не змінювалися комерційні умови доставки, гарантії чи повернення. Не створювалися масові сторінки міст або варіанти сторінок під кожну ключову фразу. Критерій для подальших текстів — конкретна допомога у виборі товару, а не задана кількість слів. Джерело: [корисний контент для людей](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).

## Як оцінювати органіку

Зафіксувати дату публікації й порівнювати наступні повні 28 днів із попередніми 28 днями. Нові сторінки оцінювати окремо від старих; враховувати сезонність і зміни асортименту.

| Рівень | Що дивитися |
|---|---|
| Індексація | Включені/виключені URL за sitemap, причина виключення, canonical і останній обхід |
| Попит | Покази й запити для нових груп, товарів та артикулів |
| Сніпети | CTR разом із позицією, типом запиту й пристроєм; сам CTR без контексту недостатній |
| Бізнес-ефект | Органічні переходи до товарів, звернення й замовлення за наявності погодженої аналітики |
| Досвід | Польові LCP, INP і CLS за пристроями, якщо є достатня кількість даних |

Приклади напрямків для перевірки в Search Console: категорійні запити «ручний інструмент», «освіжувачі повітря для авто», брендові «AREON», товарні «AREON FW06», запити моделі «запчастини Ford Focus II». Це гіпотези наміру, не виміряні частотності чи обіцянка позицій.

Для Google — sitemap та URL Inspection для вибраних пріоритетних адрес. Повторні запити обходу однієї адреси не прискорюють його й не гарантують включення. Приймання IndexNow із попередньої роботи не є підтвердженням Google-індексації; повторно ту саму партію тут не відправляли. Джерело: [повторний обхід Google](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl).

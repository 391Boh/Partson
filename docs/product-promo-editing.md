# Акційна ціна товару

У повній формі редагування та в окремому полі адміністратора акційна ціна задається в євро. Порожнє поле повної форми залишає поточну ціну, `0` прибирає акцію. Підтримуються крапка або кома та до двох десяткових знаків. Зміна лише акції не переписує ціну продажу, закупівельну ціну чи залишок. Запізніле завантаження поточної акції не затирає введений текст.

Обидва API оновлення цін перевіряють підтвердження 1С. Якщо відповідь не містить потрібного значення або повертає старе, сайт повторно читає товар без кешу. Перевіряються також одночасні зміни звичайної й акційної цін. Без підтвердження API повертає помилку, а форма зберігає введені дані. Якщо блок ціни у відповіді 1С не містить поля `Акція` (модуль `ОбщегоНазначения` старіший за підтримку акцій), помилка прямо називає застарілий модуль.

Запис працює лише після завантаження в робочу базу оновленого `ОбновитьТовар` (репозиторій конфігурації `partson-1c-config`, коміт `65b9795f` і новіші). Станом на 21.10.2026 у робочій базі стара версія: `edit` поле `Акція` ігнорує, а `prices` його не віддає.

Підтверджена акційна ціна тимчасово перекриває старі серверні знімки за кодом і артикулом. Сховище спільне для модулів маршрутів Next; нове сканування, розпочате після запису, знову стає джерелом істини. Приватна ціна не додається до публічного об’єкта товару. Публічний API продовжує віддавати лише ознаку акції та її відсоток.

Перевірки без запису в робочу 1С:

```sh
node scripts/test-product-stock.mjs
node scripts/test-promo-snapshot-edits.mjs
node scripts/test-product-admin-mutations.mjs
node scripts/test-product-edit-modal.mjs /path/to/playwright/index.mjs
```

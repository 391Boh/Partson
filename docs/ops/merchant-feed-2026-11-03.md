# Merchant-фід: завершення розгортання 03.11.2026

## Результат

Обидві адреси відповідають HTTP 200 та повертають однакові 1644 унікальні
товари: 1617 у наявності, 27 без залишку. Свіжа генерація з 1С пропустила
0 записів. Усі ціни між двома HTTP-фідами збігаються.

- Основна адреса: `https://partson.shop/google-merchant-feed.xml`.
- Сумісна стара адреса: `https://partson.shop/merchant-feed.xml`.
- Повна генерація: щогодини на 17-й хвилині, `17 * * * *`.
- Служба cron активна та ввімкнена при запуску сервера.
- Зміни акаунта Merchant Center не виконувались: час повторного
  завантаження й обробки Google визначає налаштування джерела в акаунті.

## Що змінено

1. Автооновлення явно використовує `maxItems: null`. Старий
   `MERCHANT_FEED_MAX_ITEMS=1000` більше не обрізає публічний фід.
   Ліміт також вимкнений у локальній та серверній конфігурації.
2. Повна production-збірка створена окремо. Робочий вебзастосунок
   переключений після перевірки з можливістю відкату. Процес авторизації
   не перезапускався.
3. Погодинний cron та очищення route-cache спрямовані на активний реліз.
   Новий реліз має власний каталог журналів.
4. Старий Nginx alias для `/merchant-feed.xml` замінений проксіюванням
   на спільний обробник актуальних публічних цін. Обидва фіди тепер
   мають однаковий ETag та ціни.
5. Примусово оновлено кеш товару `РТ-00001140`: ціна сторінки
   узгоджена з публічним API та фідом — 178 грн на момент перевірки.
6. Прибраний лише тимчасовий кеш компілятора нового релізу (266 МБ).
   Кеші даних та фото збережені.

## Перевірки

- Регресійний тест: старе оточення з лімітом 1000 не обрізає 1600
  тестових товарів ні при першій генерації, ні при погодинному оновленні.
- На зібраному production-кандидаті примусово встановлено ліміт 1000
  та застарілу тестову дату його копії знімка: HTTP-оновлення повернуло
  всі 1637 тодішніх товарів. Робочі файли сайту цей тест не змінював.
- Після свіжого обходу 1С отримано 1644 товари; обидва публічні фіди
  порівняні за кодами, кількістю та цінами.
- На шести товарах, включно з повернутими після обрізання, перевірені
  Product/Offer у серверному HTML та фото. Усі фінальні ціни збігаються,
  всі фото відповіли 200. Для одного холодного фото спочатку отримано
  тимчасовий 503; повторний запит успішний. Цей факт збережений у JSON-звіті.
- Шість файлів JS/CSS головної відповідають 200.
- `nginx -t`, PM2, служба cron та збережений список процесів перевірені.
- Локальні й серверні тести цін/фіду, перевірка TypeScript та ESLint пройшли.

Публічні перевірки без секретів:
[JSON-звіт](merchant-feed-verification-2026-11-03.json).
